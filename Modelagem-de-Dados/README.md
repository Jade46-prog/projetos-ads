# Modelagem de Dados

## Sobre a disciplina
Esta pasta reúne atividades, exercícios e projetos desenvolvidos durante a disciplina de Modelagem de Dados, no curso de Análise e Desenvolvimento de Sistemas (ADS).

## Conteúdos estudados
- Conceitos fundamentais de banco de dados
- Entidades e atributos
- Chaves primárias e estrangeiras
- Relacionamentos entre entidades
- Cardinalidade (1:1, 1:N e N:N)
- Modelo Entidade-Relacionamento (MER)
- Modelo lógico e modelo relacional
- Organização e estruturação de tabelas

## Objetivo
Desenvolver habilidades para analisar, estruturar e representar dados de maneira organizada, compreendendo os relacionamentos entre as informações de um sistema.

## Atividades e projetos
Este espaço será utilizado para armazenar exercícios, diagramas, modelagens e projetos práticos desenvolvidos durante a graduação.
