# Projeto Integrado II

## Sobre a disciplina
Esta pasta reúne as atividades e o desenvolvimento do Projeto Integrado II, do curso de Análise e Desenvolvimento de Sistemas (ADS).

## Projeto: Sistema de Gerenciamento de Laboratórios
Desenvolvimento de uma solução para organizar e gerenciar a utilização dos laboratórios de informática de uma instituição de ensino.

## Funcionalidades planejadas
- Acesso para administradores e alunos
- Consulta de horários e disciplinas
- Visualização da disponibilidade dos laboratórios
- Identificação de conflitos de agendamento
- Organização de aulas em horários alternados
- Alterações emergenciais no cronograma mensal

## Etapas do desenvolvimento
- Levantamento de requisitos
- Planejamento do sistema
- Modelagem de dados
- Desenvolvimento da interface
- Implementação das funcionalidades
- Testes e validação

## Objetivo
Aplicar os conhecimentos adquiridos durante a graduação no desenvolvimento de uma solução tecnológica para um problema real.
